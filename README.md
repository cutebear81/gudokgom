# 구독곰

매달 조용히 빠져나가는 구독을 한곳에 모아, 얼마가 언제 어디로 나가는지 보여주는 iPhone 앱입니다.

- 이번 달 나가는 총액과 분야별(미디어·음악·AI·생산성 등) 비중을 그래프로
- 이름 몇 글자(초성 포함)만 치면 서비스와 요금제를 골라 금액·주기 자동 입력

- 결제일 캘린더, 달러 구독 원화 환산(자동 환율)
- 계정·로그인·서버 없음. 모든 정보는 이 iPhone에만 저장
